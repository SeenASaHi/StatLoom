# StatLoom 统计实验台 · 原型二（test2/）

依据《StatLoom 项目框架：基于交互语法的自主统计学探索环境》制作的最小原型。
与原型一（test/）的区别：

- **无预设数据**：以空数据集启动，导入门是第一个入口（粘贴 / 文件 / 逐条登记）。
- **稳定框架 + 动态主体**：顶栏与探索路径条常驻，主体按任务在「数据 / 推导 / 损失」三种布局间切换，
  布局变化不丢对象身份与计算结果（同一 DOM，仅重排与隐藏）。
- **交互语法**：对象检查器给出当前选中对象的类型、真实数值与可执行动作；
  追踪入口标注关系类型（计算依赖 / 公式组成 / 定义关系 / 理论推导 / 概念关联 / 表示映射）。
- **可恢复性**：撤销 + 重做双栈；数据集与损失配置持久化在本机（localStorage）。
- **不含预测—验证**：按文档 §13.2，预测—验证不作为本原型的必需模块。

### 迭代更新（第二批交互需求）

- **托盘升格为平级视图**：视图栏为「数据 / 托盘 / 推导 / 损失」四块；空数据默认落在托盘（导入门即入口）。
- **推导次级窗口**：分析规程的卡片只保留起点与步进板；点击步进板在浮动推导窗口中展开步骤（窗口自带步进板，可关闭，Esc 关闭，回到「0 · 起点」收起，关闭不影响已推进阶段）。
- **知识库窗口**：右侧次级窗口升级为「目录 + 内容」两栏知识库，按「统计概念 / 分析目标」收录全部 8 张卡，可自由浏览；从对象旁 📖 进入时定位到对应卡。
- **炭黑仪器面**：顶栏与底部提示栏为黑底白字（莱茵生命中性色中的 charcoal，正文区仍为冷色浅色实验室基调）。
- **点阵网格背景与点阵波浪**：整页点阵网格打底，一层缓慢行进的点阵波高亮（canvas，纯装饰、低对比、不遮挡正文）；`prefers-reduced-motion: reduce` 时只绘制静态一帧。

界面沿用莱茵生命（Rhine Lab）风格的原创演绎（evidence-based Terra faction interface，
不复制任何官方素材，图标为 Lucide ISC，见 assets/icons/LICENSE）。

## 运行

Windows 下双击 `start.bat`（端口 8124），或在本目录执行：

```
python -m http.server 8124
```

然后访问 <http://localhost:8124/> 。纯静态页面，无依赖需要安装。
（页面使用 ES Modules，需要通过 http:// 访问；直接双击 index.html 无法加载。）
数据保存在浏览器本地存储中；「清空数据集」只作用于本应用的数据，可撤销。

## 三分钟上手

1. **导入。** 打开即见导入门：把「组别, 数值」逐行粘贴进文本框（或选择 .csv/.txt 文件）。
   预览实时显示有效条数、组数与无效行的行号；至少 2 条有效记录后「导入数据集」才可用。
   导入会替换当前数据集，随时可以「撤销」。
2. **观察与框选。** 数据进入后，观测窗自动绘制分组分布。点击一个点追踪它；
   在图上拖动可以框选一个数值区间——选区带、托盘中的样本外框、检查器里的选区读数会同步联动。
3. **检查器。** 选中样本、组或数字后，对象检查器给出它的类型、数值与可执行动作
   （编辑数值 / 调整分组 / 追踪到公式 / 移除）。动作按钮上的小标签说明追踪关系类型。
4. **三种任务视图。** 顶栏「数据 / 推导 / 损失」切换布局：推导视图以分析规程为主体
   （编号步进板逐步推进推导，分支带关系标签）；损失视图以处置台为主体。切换不丢状态，
   「探索路径」条记录你走过的对象，点击可以返回。
5. **损失配置。** 平方损失与绝对损失各自记住你的候选解 a，切换目标自动恢复；
   「对照」一栏显示同一 a 在另一目标下的真实损失值，便于比较两种分析目标。
6. **撤销 / 重做。** 所有数据操作（编辑、分组、导入、清空）都可撤销与重做；
   底部状态条会报告刚发生的结果。提示与建议都可以关闭，顶栏「恢复提示」可重置。

## 覆盖范围（对照文档 §13.2 首轮原型功能）

| 文档要求 | 原型落点 |
|---|---|
| 用户数据导入与编辑 | 导入门（粘贴 / 文件 / 名称 / 表头探测 / 无效行按行号拦截）+ 托盘芯片编辑 |
| 数据表、变量和分组分布视图 | 样本托盘 + 观测窗；变量类型与观测窗口在溯源胶囊 |
| 可交互的数据点与选区 | 点选中与追踪；观测窗框选（与托盘、检查器联动） |
| 实时更新的统计量 | 复核台：n、均值、SS_T / SS_B / SS_W 与分解关系，随数据实时重算 |
| 公式项与原始数据双向追踪 | 规程实例表 ↔ 托盘 / 观测窗双向高亮 |
| 可展开、可分支、可反向追踪的推导面板 | 校准步进板 + 分支节点（标注关系类型） |
| 与当前对象关联的知识卡片 | 资料抽屉：8 张卡，数值实例随当前数据实时更新 |
| 可切换损失函数的探索画布 | 处置台：表达式、曲线、优化结果；配置按目标保留并对照 |
| 分析配置的保存、撤销、重做与比较 | 撤销/重做双栈 + localStorage 持久化 + 损失配置保留与同 a 对照 |
| 可忽略的操作提示与情境化探索建议 | 分布式情境提示 + 底部建议/状态条（均可关闭） |

## 目录结构

```
test2/
├─ index.html            稳定框架 + 动态主体（三视图网格）
├─ styles.css            全部样式与语义令牌（含原型二布局与检查器/导入门/选区样式）
├─ start.bat             一键启动本地服务器（8124）
├─ package.json          仅用于 Node 直接加载 .js 版 ESM（无需 npm install）
├─ assets/icons/         Lucide 图标（ISC）与许可证
├─ js/
│  ├─ import.js          导入解析（纯函数：表头探测 / 无效行报告 / 列序自适应）
│  ├─ data.js            数据集基座（空数据集、ID 分配）
│  ├─ stats.js           纯函数统计引擎（与原型一共用，未改动）
│  ├─ store.js           状态核心：撤销/重做、选区、视图、路径、推导窗口、损失配置、持久化
│  ├─ guidance.js        情境提示 + 探索建议 + 状态反馈（无预测、无评分）
│  ├─ wave.js            点阵波浪背景（canvas，减动效时静态一帧）
│  ├─ util.js            DOM/数字/工具提示辅助
│  ├─ main.js            稳定框架装配 + 视图布局 + 探索路径条 + 背景初始化
│  ├─ content/cards.js   知识卡片内容（含类别与摘要，供知识库目录使用）
│  └─ views/             tray / chart / inspector / dock / formula / deriveWindow / loss / drawer
└─ tools/
   ├─ check-math.mjs     数学引擎校验（自带夹具）：node tools/check-math.mjs
   ├─ e2e.mjs            端到端验证（需先启动服务器）：node tools/e2e.mjs
   └─ shot.mjs           截图：node tools/shot.mjs out.png ["页面内要执行的 JS"] [宽,高]
```

## 测试

```
node tools/check-math.mjs    # 统计引擎 20 项（SS 分解恒等式、损失最优解、IQR 规则）
node tools/e2e.mjs           # 真实浏览器端到端 66 项：
                             # 空态 → 导入门校验/提交 → 编辑 → 撤销/重做 → 框选选区
                             # → 四视图切换与状态保留 → 推导次级窗口 → 双向追踪
                             # → 损失配置 → 知识库目录 → 炭黑仪器面与画布 → 清空恢复
```

e2e 使用 Chrome/Edge 无头模式（CDP 驱动），复用本机浏览器，不安装任何依赖。
界面审计（需要 terra-faction-ui 技能）：`node <terra-faction-ui>/scripts/audit-faction-ui.mjs .`

## 已知边界

- 导入约定：「组别, 数值」两列（可自动交换、单列仅数值；首行文字按表头）；
  三列以上的行只取前两列；缺失值不建模（无效行在导入门被拦下，不进入数据集）。
- 数据集与损失配置持久化在浏览器本地；撤销/重做栈不跨会话。
- 「分析分支」（并行比较两条探索线）与统计推断、概念网络未实现，是后续扩展方向。
- 界面固定为莱茵生命的冷色浅色基调；未做触屏适配（竖屏已重组并在 480px 宽验证）。
- 对外展示时请标注 “evidence-based Terra faction interface / Hypergryph-inspired”，
  不要称为官方界面。
