# StatLoom 统计实验台（test/）

交互式统计学学习工作台的最小原型，用于验证《项目框架.md》第 7 节的交互语言：
可编辑数据集、分组分布视图、实时统计量、可展开/可分支/可双向追踪的公式推导面板、
可切换损失函数画布、知识卡片，以及可选的预测—验证机制。

数据链路是真实的：所有统计量、图、规程实例都由当前数据实时计算（数学校验见下方测试）。
界面采用**莱茵生命（Rhine Lab）风格的原创演绎**——证据基础的 Terra 派系界面，
不复制任何官方 logo、美术、截图、字体或生产素材。

## 运行

Windows 下双击 `start.bat`，浏览器会自动打开 <http://localhost:8123/>。

其他平台在本目录执行：

```
python -m http.server 8123
```

然后访问 <http://localhost:8123/> 。这是纯静态页面，没有任何依赖需要安装。
（页面使用 ES Modules，需要通过 http:// 访问；直接双击 index.html 无法加载。）

## 界面语言（terra-faction-ui）

| 维度 | 取值 |
|---|---|
| 派系 | `rhine-lab`（实验 / 样本 / 核准语义；置信度 high） |
| 深度 | `moderate` |
| 任务 | `dashboard` |
| 光色基调 | `cool-light-laboratory` 固定冷色浅色（不跟随系统深色） |
| 结构元素 | 溯源胶囊（批次 / 阶段 / 完整记录 / 观测窗口） |
| 空间档案 | 仪器主台 + 底部样本托盘 + 仪器边缘复核台 + 横贯容差轨 |
| 控件语法 | 2px 诊断板 + 测量内嵌线；按压向内校准；选中获得测量样轨 |
| 签名控件 | 样本托盘（样本舱选择器）、校准步进板（规程逐步推进） |

版面语义映射：数据是样本、操作是实验、损失函数对比是模型检验。
界面信号（黄绿=进行中的研究）与数据编码色（蓝/橙两组）是两个独立语义域，
序列色保持 dataviz 校验过的固定对。例外态（IQR 规则提示）用琥珀，且只出现在
真实规则提示上；危险红仅保留给真实的无效输入。

图标来自 Lucide（ISC 许可，见 `assets/icons/LICENSE`），以内联 symbol 使用；
其余图形均为 CSS/SVG 原创几何。

## 三分钟上手

1. **改一个数字。** 在样本托盘里把 r05 的成绩从 75 改成 95（回车确认）。开着预测门时，
   系统会先请你猜一猜均值怎么变——选一个方向，或者直接“跳过预测”。随后复核台读数、
   观测窗、规程实例全部同步更新。
2. **两个方向都能追踪。** 点击规程里的 `(yᵢ − ȳ)²`，样本托盘的偏差读数和观测窗的偏差连线
   会亮起；反过来，点击托盘芯片或图上的点，规程面板里对应的数值实例行会亮起并滚动到位。
3. **推进规程。** 规程卡片右上角的编号诊断板（`0 · 起点 → 1 · 偏差 → 2 · 平方 → 3 · 求和`）
   把推导逐步推进，每一步都有解释、依据前提和当前数据实例；点击 `0 · 起点` 可以回到起点板。
4. **混合分组。** 顶栏点“混合这些组”：组间平方和 SS_B 变为 0，原分组视图在观测窗与
   复核台中以淡色保留作对比。“还原分组”或“撤销”都可以回来。
5. **容差轨。** 台面底部的容差轨把每件样本放回它所在组的 1.5×IQR 容差区间去对照：
   区间带、刻度、超限计数一目了然；选中样本会给出“余量 / 超出栅栏”的实测读数，
   点击轨道可以就近选择样本。
6. **处置台。** 拖动 a 的虚线、在图上点按或使用卡钳滑条改变候选解；“跳到最优解”可以看到
   平方损失的最优解是均值；切换到绝对损失，最优解变成中位数——当前数据是偶数样本，
   所以是一整段区间。
7. **复核门与资料卡。** 每次预测对照都会落成一条“复核门 · 已核对”记录，附带
   `回退`（撤销本次操作）；界面上带 📖 的按钮随处可开知识卡，卡内数字跟着数据实时变化。

## 覆盖范围（对照框架七件事）

| 框架要求 | 原型落点 |
|---|---|
| 可编辑数据集 | 样本托盘：芯片式改值、组别切换、移除、登记新样本、撤销、恢复原始数据集 |
| 分组分布视图 | 观测窗：SVG 点图 + 组均值 + 样本量 + IQR 规则标记（注明依据，非错误判定） |
| 实时统计量 | 复核台：溯源胶囊、n、均值、SS_T / SS_B / SS_W 与分解关系，点击数值进入规程追踪 |
| 公式推导面板 | 分析规程：校准步进板、分支节点、双向追踪、逐观测与逐分组数值实例 |
| 损失函数画布 | 处置台：贡献线段图 + 损失曲线 + 拖动候选解 + 最优解标记与跳转 |
| 知识卡片 | 资料抽屉：8 张卡（均值/中位数/偏差/平方和分解/组内组间/平方损失/绝对损失/IQR） |
| 预测—验证 | 复核门：可选、可跳过、只对照差异不评分、支持回退；顶栏可整体关闭 |

## 目录结构

```
test/
├─ index.html            页面骨架（分区域：shell / bench+dock / tray / protocol / loss）

├─ start.bat             一键启动本地服务器
├─ package.json          仅用于 Node 直接加载 .js 版 ESM（无需 npm install）
├─ assets/icons/         Lucide 图标（ISC）与许可证
├─ js/
│  ├─ data.js            内置示例数据（教学方式 × 考试成绩，20 条）
│  ├─ stats.js           纯函数统计引擎（与界面完全解耦）
│  ├─ store.js           单一状态源 + 撤销栈 + 订阅通知 + 校准步进状态
│  ├─ guidance.js        操作入口、复核门（预测—验证）、情境提示、探索建议
│  ├─ util.js            DOM/数字/工具提示辅助
│  ├─ main.js            装配与订阅
│  ├─ content/cards.js   知识卡片内容
│  └─ views/             tray（样本托盘）/ chart（观测窗）/ dock（复核台，含容差轨）
│                        / formula（分析规程）/ loss（处置台）/ drawer（资料抽屉）
└─ tools/
   ├─ check-math.mjs     数学引擎校验：node tools/check-math.mjs
   ├─ e2e.mjs            端到端交互验证（需先启动服务器）：node tools/e2e.mjs
   └─ shot.mjs           截图：node tools/shot.mjs out.png ["页面内要执行的 JS"] [宽,高]
```

## 测试

```
node tools/check-math.mjs    # 统计引擎：SS 分解恒等式、损失最优解、IQR 规则等 20 项
node tools/e2e.mjs           # 真实浏览器端到端：渲染、步进板、双向追踪、复核门、容差轨、撤销、损失、知识卡
```

e2e 使用 Chrome/Edge 的无头模式（CDP 驱动），会复用本机已装的浏览器，不安装任何依赖。
两项测试都需要先启动本地服务器。

界面审计（可选，需要已安装 terra-faction-ui 技能）：

```
node <terra-faction-ui>/scripts/audit-faction-ui.mjs .
```

## 已知边界与后续扩展

- 数据固定为内置示例场景。**CSV 导入是第一扩展点**（框架验证场景的原始设定）。
- 只覆盖描述统计与损失最小化；抽样推断、因果不在原型范围，界面中对这条分界有明确说明。
- 界面固定为莱茵生命的冷色浅色基调（派系配色分离要求），不提供深色模式。
- 未做移动端与触屏适配（竖屏布局已重组并在 480px 宽验证），建议桌面浏览器。
- 预测门默认开启，可以随时跳过或整体关闭；所有情境提示都可关闭，顶栏“恢复提示”可重置。
- 界面为派的原创演绎：所有几何、令牌与纹理均为新写；如用于对外展示，请标注
  “evidence-based Terra faction interface / Hypergryph-inspired”，不要称为官方界面。
