# StatLoom 最小原型（test3）

数学对象驱动的统计探索工作台 · 最小原型。核心命题：**改一个数据点，整条依赖链与恒等式以单一版本原子更新，且一切可双向追溯、可撤销。**

依据：`docs/2026-10-13-原型设计.md`（v1.2）与三份实现规范（`docs/AST操作集规范.md`、`docs/统一依赖图规范.md`、`docs/状态与事务规范.md`）。

## 运行

```
npm install
npm run dev          # 开发服务器 http://localhost:5173
npm test             # Vitest：内核 / 图 / 历史 / 事务 / 性质 / 层界 / 比例尺 / 变异演练
npx tsc --noEmit     # 类型检查
npm run build        # 生产构建（dist/）
node tools/e2e.mjs   # 端到端（CDP 驱动本机 Chrome/Edge；需 dev 服务器在运行）
node tools/shot.mjs  # 截图（.shots/，含灰度与窄视口）
```

## 界面契约（statloom-ui）

```
surface:      dark（暗场点云 + 纸白窗口）
layers:       system（L0 点云 + L1 三窗口 + L2 读数面 + L3 状态标注 + 56px 导轨）
math object:  变异分解（SS_T = SS_B + SS_W）
signal owner: 当前选中/拖动的观测点，及其同帧变化的偏差线、读数、公式项
ambient cloud: on（簇 = 组；波浪 = 数据变化；光带 = 当前对象）；空态匀速扫描待机
motion budget: 一次入场 + 一次状态响应；prefers-reduced-motion 有完整平价
primary action: 拖动一个点，恒等式在单一版本上重组
```

**本项目唯一偏离**：L1 窗口 `rgba(255,255,255,.72)` + `blur 12px`（默认 .88/10px）；L2 读数面保持完全不透明。
**实现期调整（已回写设计文档 §10.3）**：平方块默认关——基准尺度下方形几乎必然裁切，映射规则与裁切标记不变。
三条不变量：读数只在不透明面上；荧光黄跟随状态（选中/变化），不跟随 hover；背景不承担任何读数。

## 三分钟上手

1. **载入基准**：左导轨「基准」→ 验收用例 A（A=[4,5,6]、B=[7,8,9]）。读数条立即给出 SS_TOTAL 17.50 / SS_BETWEEN 13.50 / SS_WITHIN 4.00 / 残差 0.00。
2. **拖动一个点**：在画布上水平拖动（纵向跨行即换组）。拖动中状态条显示「预览：…（未提交）」，读数同帧更新；松手提交，`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做；Esc 取消预览且零残留。
3. **双向追溯**：点击画布上的点 → 右侧检查器给出定义（KaTeX）、实例代入、输入来源（含版本）；「被谁引用」列出下游对象与视觉表示。点任意引用跳转；点关系图节点可选中同一对象；点公式下方的逐项明细 chips 可回到每个数据来源。
4. **关系图**：观测级节点默认折叠（「仅显示层」）；选中某观测时它的偏差链自动展开。Tab 遍历、Enter 选中、Space 折叠；「视觉映射边」开关只影响显示，检查器的表示列表不受影响。
5. **键盘等价路径**：Tab 聚焦数据点 → ←→ 调值（Shift ±5）→ Enter 提交；换组用检查器「移到另一组」。
6. **导入 / 导出**：左导轨「导入」可粘贴两列 CSV（必须有表头；整批预检，任何坏行阻止导入）或快照 JSON（结构 → 引用 → 沙盒重建 → 原子换入）；「导出」给出源状态快照 JSON。

## 验收用例怎么走（手动对照）

| 用例 | 操作 | 预期 |
|---|---|---|
| A 基准数据 | 载入基准 | 读数四项如上；画布/读数/检查器/关系图同值 |
| B 整组平移 | 内核性质测试覆盖（不设 UI 按钮） | SS_W 与组内偏差不变、观测 ID 稳定 |
| C 单点移动 | 拖动 r01 或键盘改值 | A 组链与总体均值链更新；B 组 gdev 链更新；B 组观测偏差不变 |
| D 空组/全同值 | 把 A 组移空（检查器换组）或导入全同值数据 | 组均值显示「未定义」并给理由；不显示 0 或过期值 |
| E 动画中断 | 拖动中按 Esc / 快速连续操作 | 数学状态只来自已提交版本；取消零残留 |
| F 前提未知 | —（本原型无推断功能，天然不涉及） | — |

## 边界与声明

- 数据规模：≤200 观测、≤8 组；超出明确拒绝（capacity-exceeded）。
- e2e 固定桌面 1440×900；窄视口 900×1200 是**独立**测试目标（截图 + 布局断言），不被桌面通过代表。
- 环境层点云是数据场的**示意表达**（簇≈组、密度≈规模量级），不承载读数；正式数据一律来自用户载入。
- statloom-ui 审计脚本：0 FAIL。唯一 WARN 为启发式"示意数据标注"：注记（"背景点云为数据场的示意表达…"）在 TS 渲染的窗内文本中，而审计脚本只收集 `.html/.css/.js/.mjs`、不扫描 `.ts`——属工具盲区，非缺失。
- 视觉语言为对公开样式的原创演绎，不含商业字体与官方素材。
